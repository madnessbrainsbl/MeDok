# Выписки

Локальная программа на Rust для подготовки выписки формы 027/у из направления ODT формы 057/у. Врач проверяет поля, дополняет осмотр и анамнез, затем сохраняет PDF и при необходимости собирает пакет приложений. Программа не ставит диагноз.

## Готовые сборки

В [последнем релизе](https://github.com/madnessbrainsbl/vypiska/releases/latest) лежат `vypiska-windows7-x64.exe` для Windows 7 x64 и `vypiska-alt10-x64.tar.gz` для «Альт Рабочая станция» 10 x64. На Linux распакуйте архив и запустите `vypiska`. Для окна нужен X11 или Wayland. Для включения направления ODT в общий пакет установите LibreOffice.

## Сборка

```powershell
cargo build --release
cargo test
```

Исходники общие, бинарники для Windows и Linux собираются отдельно. На Windows 7 используется `pwsh -File сборка.ps1`: скрипт требует установленный nightly toolchain и цель `x86_64-win7-windows-msvc`, проверяет импорты PE и кладёт готовый EXE рядом с `Cargo.toml`. Linux-версию для «Альт 10» собирайте внутри «Альт 10»: бинарник, собранный на системе с более новой glibc, может там не запуститься. Для графического окна нужен X11 или Wayland.

## Данные

Настройки, журнал и карточки пациентов программа хранит в `vypiska-данные` рядом с исполняемым файлом либо в каталоге настроек пользователя. Карточки защищаются DPAPI в Windows и XChaCha20-Poly1305 в Linux. Не пересылайте этот каталог и готовые медицинские документы вместе с исходным кодом.

Приём снимков с телефона включается врачом в окне программы. QR-код содержит случайный код доступа для текущего сеанса; передача идёт по HTTP в локальной сети. Используйте доверенную сеть или режим модема телефона.

В `tests/fixtures` лежат только искусственные документы и изображения. Настоящие направления, печати, подписи, карточки и PDF пациентов в репозиторий не входят. `.gitignore` разрешает добавлять только перечисленные исходники и тестовые файлы.
